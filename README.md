# 窓汚れ検知の最小PoC ── カメラ監視を現場で生き残らせる

カメラで現場を監視する仕組みは、「見ている窓そのものが汚れる」と役に立たなくなる。
このコードは、**窓の汚れ（ゆっくり・場所固定）と、噴霧の異常（速い・噴霧領域）を、
取り違えずに切り分けられるか**を、合成データで実証する最小コードです。

噴霧の異常検知そのものについては、別記事・別リポジトリを参照。これはその発展版です。
https://note.com/major_bobcat4320/n/n393754f77462

- 前作：明るさの時間変化による検知 → https://github.com/takeyuyu/spray-anomaly-poc

## このコードが示すこと

カメラ映像が暗くなる原因は2つある。

- **噴霧の異常**：速い変動（1秒以内）、噴霧している場所で起こる
- **窓の汚れ**：ゆっくりした変化（分〜時間）、特定の場所に固定的に積もる

この2つを取り違えると、現場で誤報を生み、監視システムが使われなくなる。

そこで、**「速いか/遅いか」と「場所」** で2つを切り分ける。
速くバタつけば噴霧の異常、ゆっくり暗くなれば窓の汚れ。
別々のチャンネルで検知することで、取り違えを防ぐ。

## 重要な前提

- **実データは一切使用していません。** すべてプログラムで生成した合成データです。
- これは「原理が成立するか」を確かめる第一歩であり、実機での動作を保証するものではありません。
- 実際の導入には、現場データでの検証や各種の確認が別途必要です。

## 実行方法

```
pip install numpy matplotlib
python dust_poc.py
```

実行すると、判定結果がコンソールに表示され、同じフォルダに2枚の図が出力されます。

- `dust_poc_frames.png` … 窓が5分かけて徐々に汚れていく様子（合成）
- `dust_poc_result.png` … 窓の汚れと噴霧の異常を別チャンネルで検知し、取り違えない様子

※ 日本語ラベルの表示には日本語フォント（Noto Sans CJK JP など）が必要です。
